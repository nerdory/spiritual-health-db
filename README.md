# 🌱 Spiritual Health & Vibes Dashboard

An open-source, reproducible assessment tool designed for churches, fellowships, and ministry groups. It processes survey data from Google Forms via Google Sheets and visualizes longitudinal spiritual growth on interactive Plotly radar charts.

---

## 🚀 How to Duplicate This Setup for Your Group

Anyone can replicate this system for their own organization by following these 4 steps:

### 1. Duplicate the Google Form
Create a Google Form with the following core fields:
- **First / Preferred Name** (Short Answer)
- **4-Digit PIN** (Short Answer — set Regular Expression validation to `^[0-9]{4}$`)
- **Group / Season Selection** (Multiple Choice or Dropdown)
- **Track Selection** (Believers vs. Seekers)
- **24 Assessment Questions** (Linear scale 1 to 5)

> **Note:** Member User IDs are automatically generated by combining Name + PIN (e.g., `Ka Ming` + `1234` = `KAMING1234`).

### 2. Connect Form to a Public Google Sheet
1. Link your Google Form to a Google Sheet (**Responses** tab $\rightarrow$ **Link to Sheets**).
2. Click **Share** in the top-right corner of the Google Sheet.
3. Change access to **"Anyone with the link can view"**.
4. Copy your Sheet ID from the browser URL:
   `https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID_HERE/edit`

### 3. Deploy Your Own Streamlit App
1. Fork or clone this repository to your GitHub account.
2. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Click **New App** and select your repository.
4. Go to **Advanced Settings...** $\rightarrow$ **Secrets** and configure your credentials:

```toml
[general]
sheet_id = "YOUR_GOOGLE_SHEET_ID_HERE"

[seasons]
"Spring 2026" = ["Alpha Group", "Beta Group"]

[passcodes]
"Spring 2026" = "yourleaderpasscode"
```

### 4. Configure the Assessment Itself (No Code Changes)

The axis layout and answer scoring are also secrets, so you can revise the
Google Form and update the dashboard from the Streamlit Cloud secrets editor
without touching the code. Copy the `[assessment.*]` sections from
`.streamlit/secrets.toml` as your starting point:

```toml
# Which question numbers belong to each axis. Key order = display order.
[assessment.axis_mapping]
"Axis 1: Abiding & Rest" = [1, 2, 3, 4]
"Axis 2: Scripture & Mind Renewal" = [5, 6, 7, 8]
# ...

# Optional per-axis colors (hex). Missing axes fall back to a default color.
[assessment.axis_colors]
"Axis 1: Abiding & Rest" = "#E63946"
# ...

# Per question: its answer options in ASCENDING score order.
# The FIRST option scores 1 point, the LAST scores 5 — score = position.
[assessment.questions.believers."Axis 1: Abiding & Rest"]
"1. How consistently do you spend personal time in prayer and reflection with God?" = [
  "Rarely or never",
  "A couple of times a month",
  "About once a week",
  "Several times a week",
  "Daily or nearly daily",
]
# ... (seekers live under [assessment.questions.seekers.<axis>])
```

> **Scoring is positional:** to change how an answer scores, reorder it in the
> list. To add a question, add its key + options under the right axis and
> update `axis_mapping`. Answers are matched exactly, then by unique prefix,
> so minor wording drift between the doc and the live form is tolerated.
>
> **Note:** Streamlit Cloud restarts the app automatically when secrets are
> edited, so changes apply within a minute. Locally, restart
> `streamlit run app.py` after editing `.streamlit/secrets.toml`.
